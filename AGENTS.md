## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## UI implementation

- Read `DESIGN.md` before changing layouts, typography, colors, spacing, or interaction patterns.
- Use the relevant project UI/UX skill for interface work, especially `ui-ux-pro-max`, `frontend-design`, `tailwind-4-docs`, or `web-design-guidelines` when applicable.
- Preserve the established Vercel-inspired visual system unless a redesign is explicitly requested.
- Validate both light and dark themes, keyboard focus, responsive behavior, and contrast-sensitive states after UI changes.
